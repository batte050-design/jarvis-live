How a scanner finds a misfire

A misfire is a cylinder not burning its charge properly. The scanner never feels the engine. It watches three things that a misfire disturbs: the crankshaft speeding up and slowing down, the oxygen sensor reading the left-over air, and the computer counting its own bad firings.

Step 1. The cylinder fires, the crank speeds up

Combustion pushes the piston down hard, so the crankshaft accelerates through that cylinder's power stroke. A miss means no push, so the crank stumbles. A good engine has a small, even wobble; a misfiring one has a big spike at one cylinder.

Step 2. The crank sensor reports the wobble

The crank position sensor gives the computer a tooth-by-tooth timing pulse, and the cam sensor tells it which stroke each cylinder is on. From those pulses the computer measures each cylinder's acceleration and compares it to the others.

Step 3. The computer scores every firing event

Each firing is labelled a good or bad sample. The computer keeps a running count per cylinder, in a window of 200 engine revolutions, under two headings: Type A, a miss big enough to damage the catalytic converter, and Type B, a smaller miss that raises emissions. Type A is roughly a 2 to 20 percent misfire rate depending on engine, Type B around 2 percent.

Step 4. The oxygen sensor confirms it

A cylinder that misses passes unburnt oxygen into the exhaust. The upstream oxygen sensor sees that extra air, so the computer knows the fault is real combustion, not a sensor lying about speed.

Step 5. It stores a code and the freeze frame

When the count crosses the threshold, the computer lights the check engine lamp and stores a code. P0300 means random or multiple cylinders. P0301 through P0308 name the cylinder number directly. Some makers use their own codes, and a manufacturer tool reads them all.

A simple diagram, in words

Crank sensor and cam sensor feed timing into the engine computer. Inside the computer, four per-cylinder counters sit side by side, each one ticking up when that cylinder stumbles. The oxygen sensor feeds in on the side as a second opinion. When one counter crosses its line, the computer writes the code and freezes the data. That frozen snapshot, not the code, is what tells you when it happened: cold start, idle, hard acceleration or cruise.

Single cylinder

A real example: P0301 on a Toyota Premio

Faulty coil on cylinder one. Code P0301. Freeze frame shows 620 rpm, idle, coolant 82 degrees, load 14 percent. So the miss is worst at idle and only on one cylinder. Move the coil to cylinder two, clear the code, drive it. The code follows the coil to P0302. That swap test proves the coil, not the plug or the injector.

Random or multiple

A real example: P0300 at cruise

All four counters ticking, worse at 2,500 rpm and light load. Plugs and coils all sound. The upstream oxygen sensor traces to a vacuum leak at the intake gasket, leaning every cylinder at once. Leak fixed, trims come back, counters stop. P0300 is rarely four separate faults; it is usually one shared cause.

Practical

What separates a scanner from a guess

A scanner can tell you which cylinder, at what rpm, at what temperature, at what load, and whether the miss is bad enough to hurt the converter. A compression test, a spark test and a coil swap turn that into a diagnosis. The scanner narrows the field; it does not name the broken part on its own.

The order I would work it

Read the code and the freeze frame first, so you know when and where. Look at the per-cylinder misfire counters live, not just the stored code, because a partly failing coil often has not set a code yet. Then swap the suspect part to another cylinder and re-read. If the code and the counter follow the part, you have your answer.

Misfire detection is arithmetic on crankshaft speed, confirmed by exhaust oxygen, then frozen into a snapshot you can act on.
