How a scanner finds a misfire

A misfire is a cylinder failing to burn its fuel at the right moment. The scanner never sees the flame - it watches the crankshaft, and counts how unevenly it turns.

Diagram, left to right: [ CYLINDER FIRES ] -> [ CRANKSHAFT SPEEDS UP ] -> [ CRANK SENSOR pulse gets shorter ] -> [ ECM counts each slow pulse as a misfire ] -> [ STORED AS P0300 + WHICH CYLINDER ]

Step by step

Inputs

1. The ECM knows when each cylinder should fire

The camshaft sensor tells it which stroke each cylinder is on; the crankshaft sensor tells it exactly where the crank is. Together they give the firing order a clock to measure against.

Physics

2. A firing cylinder kicks the crank forward

When a cylinder burns properly it pushes the piston down hard and the crankshaft speeds up for a moment. That little acceleration is the signature of a healthy power stroke.

The fault

3. A misfiring cylinder does not

No burn, no push. The crank slows just after the point that cylinder should have fired - a small dip the ECM can measure from the crank sensor's pulse timing.

Counting

4. The ECM counts the dips

Each crank revolution it compares the expected acceleration with the real one. Every missing or weak acceleration is logged against that cylinder's misfire counter, then expressed as a percentage of total firing events.

Output

5. It sets the code and freezes the scene

P0300 means random or multiple cylinders. P0301 through P0312 name a single cylinder. A pending code appears on the first fault; an active code needs the fault to recur in two consecutive drive cycles.

Freeze frame

6. It saves what the engine was doing

At the moment the code set, the ECM stores rpm, engine load, coolant temperature, vehicle speed and the misfire count itself. This is your evidence of when it happened, not just that it did.

Worked example - a real pattern

A 4-cylinder Toyota idles rough and shakes under load. The scan shows P0304 - cylinder 4 misfire. Live data at idle: cylinder 1 at 0, cylinder 2 at 0, cylinder 3 at 1, cylinder 4 at 340 counts and climbing. Freeze frame: 2,100 rpm, 38 percent load, 87 degrees C.

What that tells you: misfire is isolated to one cylinder (not P0300), it is worst low in the rev range (ignition or compression weakness shows most at low speed and light load), and it is a hard, repeatable fault, not an intermittent one. What it does not tell you: whether the cause is the coil, the plug, the injector or valve sealing. Those need a swap test, a spark check and a compression reading - the code names the cylinder, never the part.

What each code shape means

Multiple / random

P0300

Scattered across cylinders or not tied to one. Points to a shared cause - fuel pressure, vacuum leak, worn plugs across the board, or a crank signal problem.

One cylinder

P0301 to P0312

Isolated to a single cylinder number. Narrow it with a coil/plug swap; if the misfire follows the part, the part is the cause; if it stays put, the fault is in the cylinder itself - compression, injector or wiring.

Status

Pending vs stored

A pending code is a first-sighting fault, cleared if it does not repeat. A stored code has met the two-cycle threshold. History means it happened and later stopped.

Where the method has limits

Crank-speed detection is fast and cheap but it is indirect. It is best on an even, four-stroke idle; it struggles with a rough idle from a modified cam, with light misses at very low load, and with some rough-running faults that are not cylinder misfires at all. It also cannot tell you which component failed. A misfire code is a symptom with a location, not a diagnosis - that is why the follow-up test is always a swap, a pressure reading or a waveform, never the code alone.

Definitions

ECM - the engine control module, the computer reading the sensors and setting codes. Crank sensor - reads engine speed and position. Cam sensor - reads which stroke each cylinder is on. Freeze frame - the snapshot of sensor values saved at the moment a code sets. Drive cycle - a start-to-warm run the ECM needs to confirm a repeat fault.

The scanner saw a number, then invented the word misfire to describe it. The code says which cylinder and roughly when - the repair still has to be proven at the car.
